# Python 中的 `if __name__ == '__main__':` 是什么意思？

## 一句话结论

`if __name__ == '__main__':` 用来判断当前 Python 文件是不是**作为主程序直接运行**。如果是，就执行 `if` 里面的代码；如果这个文件只是被别的程序 `import` 导入，就跳过里面的代码。

---

## 1. `__name__` 是什么？

每个 `.py` 文件在 Python 里都叫一个**模块**。每个模块都有一个内置变量 `__name__`，Python 会自动给它赋值。

赋值规则如下：

| 运行方式 | `__name__` 的值 | `if` 条件是否成立 |
| --- | --- | --- |
| 直接运行 `python demo.py` | `'__main__'` | 成立 |
| 在别的文件中 `import demo` | `'demo'` | 不成立 |

也就是说：

```python
if __name__ == '__main__':
```

等价于在问：

> 这个文件现在是被直接运行，还是被导入？

直接运行时，答案是“是”；被导入时，答案是“否”。

---

## 2. 用一个例子看效果

新建 `demo.py`：

```python
def add(a, b):
    return a + b


print("模块被加载")

if __name__ == '__main__':
    print("文件被直接运行")
    print("1 + 2 =", add(1, 2))
```

### 情况一：直接运行

在终端执行：

```bash
python demo.py
```

输出：

```text
模块被加载
文件被直接运行
1 + 2 = 3
```

此时 `__name__ == '__main__'` 成立，所以 `if` 里面的两行都会执行。

### 情况二：被其他文件导入

新建 `use_demo.py`：

```python
import demo
```

运行：

```bash
python use_demo.py
```

输出：

```text
模块被加载
```

此时 `demo.py` 的 `__name__` 是 `'demo'`，不是 `'__main__'`，所以 `if` 里面的代码不会执行。

注意：`print("模块被加载")` 写在 `if` 外面，所以无论直接运行还是被导入，它都会执行。

---

## 3. 为什么要这样写？

老师问的 “why”，主要是想让你说明它的用途。

### 原因一：区分“工具代码”和“入口代码”

一个文件里通常既有函数定义，也有测试代码。

例如：

```python
def add(a, b):
    return a + b


if __name__ == '__main__':
    print(add(1, 2))
```

`add()` 是给别人复用的函数，而 `print(add(1, 2))` 是给自己测试用的。把测试代码放进 `if` 里，别人导入这个文件时就不会被迫看到测试输出。

### 原因二：避免导入时产生副作用

如果文件里有这些代码：

- 读取文件
- 连接数据库
- 爬取网页
- 训练模型
- 画图
- 大量计算
- `input()` 等待用户输入

直接写在模块顶层，一旦被 `import`，这些操作就会立刻执行。放进 `if __name__ == '__main__':` 里，就可以避免这种副作用。

### 原因三：让文件既能复用，也能单独运行

加上这个判断后，同一个文件可以有两种身份：

- 被导入时：作为一个模块，提供函数或类；
- 直接运行时：作为一个完整程序，执行演示或测试。

这正是它最常见的价值。

---

## 4. 常见误区

### 误区一：每个文件都必须写

不是。只有当你希望“被导入时不执行某些代码”时才需要写。一个纯函数工具模块可以不写。

### 误区二：`'__main__'` 是某个函数名

不是。`'__main__'` 只是一个字符串，是 Python 给“主程序模块”约定的名字。

### 误区三：写在 `if` 里的代码导入时完全不可见

不是“不可见”，而是“不执行”。函数定义、类定义仍然可以被导入使用。

---

## 5. 总结

`if __name__ == '__main__':` 是 Python 中非常常见的写法。

它的作用是：

1. 判断文件是不是被直接运行；
2. 让测试代码只在直接运行时执行；
3. 避免模块被导入时产生不必要的副作用；
4. 让同一个文件既能作为模块复用，又能作为脚本单独运行。

所以，老师布置这个作业，就是希望你理解：**Python 文件既可以是程序入口，也可以是被导入的模块，而这行代码就是区分这两种状态的开关。**
