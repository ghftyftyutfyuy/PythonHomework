> 上级索引见 [`experiment1/README.md`](../README.md)，仓库首页见 [`README.md`](../../README.md)。

## 一、题目要求

某团队每月有一份 `sales_raw.xlsx`，字段为 日期、销售员、产品、数量、单价、地区，存在空值、重复行与负数量等脏数据。编写 Python 脚本读取原始表，完成清洗与统计，输出 `report.xlsx`。

1. **数据清洗**：删除关键字段缺失的行，剔除数量小于等于 0 的异常行，按全字段去重；
2. **统计维度**：按销售员汇总销售额（数量乘单价），按地区汇总销售额，并给出月度总额；
3. **输出 `report.xlsx`**：含「明细清洗后」「按销售员」「按地区」「总览」四个工作表；
4. **约束**：不得修改原始文件；对缺失字段、空文件、无有效数据等情况需给出明确报错或提示。

**验收标准**：给定样例数据能一键运行生成正确报表；统计数值与人工核对一致；异常输入不崩溃且有可读提示。

## 三、运行方式

```bash
cd E:\PythonHomework\experiment1\excel
python src\create_sample.py      # 可选：重新生成样例原始数据
python src\generate_report.py   # 生成 output\report.xlsx
```

脚本用 `__file__` 自动定位 `data/` 与 `output/`，从任意目录运行都可以；运行窗口会直接打印进度与汇总数字，不需要打开 Excel 才能看结果。

依赖：`pandas`、`openpyxl`，安装命令 `pip install pandas openpyxl`。

## 四、实现要点

| 环节 | 实现 |
| --- | --- |
| 字段校验 | `load_data()` 检查文件是否存在、是否为空、六个必需字段是否齐全，缺失即抛出可读错误 |
| 清洗 | `clean_data()` 依次删除关键字段缺失行、把数量与单价转为数值、剔除数量小于等于 0 的行、按全字段去重；清洗后为空则报错 |
| 统计 | `generate_statistics()` 用 `groupby` 按销售员、地区汇总销售额；日期转月度周期得月度总额；总览给出四个指标 |
| 输出 | `save_report()` 用 `pd.ExcelWriter` 写四个工作表，并在「总览」下半部分追加月度销售额 |
| 容错 | `main()` 分别捕获文件不存在、数据不合法与未知异常，打印中文提示后退出；全程只读原始文件 |

## 五、运行结果（Python 3.11 实跑）

样例数据共 13 行，其中 2 行关键字段缺失、2 行数量小于等于 0、1 行完全重复，清洗后保留 **8 行**有效记录。

```text
正在读取 ...\data\sales_raw.xlsx ...
正在清洗数据 ...
正在生成统计报表 ...
正在输出 ...\output\report.xlsx ...
报表生成成功！
  - 有效记录数: 8
  - 总销售额: 4000.00
```

| 工作表 | 内容 |
| --- | --- |
| 明细清洗后 | 8 行有效记录，含计算出的销售额列 |
| 按销售员 | 李四 1400、王五 1400、张三 1200 |
| 按地区 | 华北 1400、华南 1400、华东 1200 |
| 总览 | 总销售额 4000、有效记录数 8、销售员数量 3、地区数量 3，并附月度：2024-01 为 2340、2024-02 为 1660 |

数值与人工核对一致：4000 = 2340 + 1660，按销售员与按地区两个维度合计也都等于 4000。
